完整告别

2026 年 5 月至 2026 年 8 月，这个小小的电费监控站陪同学们走过了三个月。

我们为每天 14:00 的全校电费采集努力过：从登录验证码、滑块，到查询接口一次次限流升级，都一一适配。但 epay 查询接口的配额限制最终导致采集账号被封禁，大规模采集无法继续——2026 年 8 月 8 日之后，数据停止了更新。

感谢第一位 PR 提交者 Mentat-Uran 和每一位提 issue、报 bug 的同学，你们的帮助让这个项目不断变得更好 💪

服务恰好止步于 2026 年暑假之末，未能等到 2026 级的同学们开学。

数据不会消失：历史数据仍可浏览至域名到期，也完整保留在 GitHub 归档仓库中。想继续查电费的同学，可以试试针对单个宿舍的 nju_electric_monitor（单房间查询与可视化，需注册 GitHub 账号）。

再见，感谢陪伴。—— 荣子

常见问题

数据还能看吗？

可以。历史数据仍可在各视角页面浏览，直至域名到期。

为什么停止服务？

epay 查询接口实施配额限制，采集账号被封禁，大规模采集不可持续。

怎么找我的房间？

通过上方「我的房间」卡片配置房间号，即可查看该房间的历史数据。

原始数据在哪里？

完整历史数据保留在 GitHub 归档仓库，可 git clone 获取（database/summaries/ 及 database/ 目录）。

想继续查电费怎么办？

可试用nju_electric_monitor（其他同学维护的针对单个宿舍的电费查询与可视化项目，需注册 GitHub 账号）。对熟悉 GitHub 的同学来说，只需配置好 Secrets 并部署 GitHub Pages，就能在公网查看自己宿舍的电费；但对小白来说，这套部署流程可能比较复杂，需要一定的动手能力。

数据与后继

历史数据仍可浏览至域名到期；域名到期后，请通过 GitHub 归档仓库 获取源码与数据（可 git clone）。

如需继续查询电费，可试用针对单个宿舍的 nju_electric_monitor（单房间查询与可视化，需注册 GitHub 账号）。
