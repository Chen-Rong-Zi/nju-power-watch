# 关于 电费监控系统

南京大学宿舍电费查询工具

大家好，我是 [荣子](https://github.com/Chen-Rong-Zi)。

这个项目最初是软件学院《人工智能驱动软件工程》课程的大作业。今年 5 月，我在校园集市上第一次宣传了它，没想到收到了非常多同学的关注和反馈。

感谢每一位提 issue、报 bug 的同学，你们的帮助让这个项目不断变得更好。

---

## 功能更新

**2026 年 5 月** · 项目启动
- 每日电费数据自动采集，GitHub Actions 定时更新
- 电费趋势图表、余额预警、充值建议
- 全校电费总览（校区视角）、耗电量排行榜（楼栋视角）
- 耗电量直观类比：将度电转为小米 SU7、Optimus、DeepSeek 等科技场景
- 校园集市首次宣传，收到大量反馈，项目正式起步

**2026 年 6 月** · 数据可视化增强
- 耗电量分布图表（交互式直方图与分布拟合）
- 数据自动回退：无数据时自动切换至最近可用日期
- 房间 ID 自动发现扫描，持续扩充宿舍覆盖
- 支持 Docker 部署

**2026 年 7 月** · 体验优化
- 房间 ID 配置迁移至 JSON 格式，管理更便捷
- 登录方式升级，集成 NJUlogin 简化登录流程
- 页面状态持久化：自动保存校区、楼栋等浏览位置

**2026 年 8 月** · 楼层分析上线
- 按楼层分析耗电差异，帮助识别高楼层 vs 低楼层用电情况
- 图表点击交互、底部抽屉详情、FAB 悬浮按钮
- 灵感来自校园集市上关于"高楼层更耗电"的热门讨论
