# 断电瞬间动画 + 灰烬氛围 — 设计文档

> 日期：2026-08-10
> 状态：已获用户确认（brainstorming 流程定稿）
> 范围：docs 前端告别页面的死亡感 UI 增强

## 1. 背景与目标

项目已于 2026-08 停止维护（epay 配额限制 + 账号封禁）。当前"项目已死亡"的传达全部依赖**静态常驻元素**（整站黑白滤镜 + 顶部常驻横幅 + 告别文案），没有任何动态的"死亡瞬间"表达。

本设计为告别页面增加动态的死亡叙事：

1. **断电瞬间动画**：进入页面时，从彩色瞬间跌入黑白（闪断 → 纯黑 → 亮起黑白），传达"服务终止/断电宕机"
2. **持续环境氛围**：动画结束后，整站黑白常驻 + 灰烬缓缓飘落，营造"项目已燃尽、灰飞烟灭"的持续氛围

用户确认的核心方向：
- 死亡感 = **两者结合**（一次性断电仪式 + 持续黑白氛围）
- 动画隐喻 = **断电瞬间**（非墓碑/蜡烛/心跳线）
- 节奏 = 快节奏约 1s
- 范围 = 全部 4 个功能页播放，但 session 内只播一次
- 结束后基调 = 维持黑白常驻
- 黑屏阶段 = 纯黑无文字
- 持续效果 = 细微环境氛围（灰烬飘落，中等密度 20-30 片）
- 灰烬性能 = 常驻飘落 + 页面隐藏/切后台时暂停

## 2. 设计原则

- **克制**：动画 <1.2s，灰烬中等密度低透明度，不遮挡内容、不喧宾夺主
- **动态灰度**：把"整站黑白"从静态改为动态驱动——先彩色后黑白，"断电"叙事才成立
- **健壮降级**：无论 JS 失败、用户禁用 JS、还是动画中途报错，页面始终兜底到黑白可用态
- **尊重用户**：`prefers-reduced-motion` 时完全跳过动画与灰烬
- **零新依赖**：vanilla JS + CSS，沿用 `shutdown-banner.js` 的注入模式

## 3. 断电瞬间动画

### 3.1 时间轴（约 1.1s）

```
彩色页面（正常渲染）
   │
   ├─ [1] flash 回光 ×3   ~360ms   overlay 连续闪白/灰 3 次
   │                              （0.12s 白 + 间隔暗，重复 3 次）
   │
   ├─ [2] black 断电       ~220ms   稳定纯黑屏（#000），无文字
   │                              ← 此期间 JS 把页面从彩色切为灰度
   │
   ├─ [3] reveal 亮起      ~500ms   overlay 淡出，露出黑白页面
   │
   ▼
黑白页面常驻（html.grayscale 生效）
```

- 总时长：flash 3×120ms + black 220ms + reveal 500ms ≈ **1.08s**
- flash 三次回光模拟断电瞬间屏幕"闪三下再黑"的经典显示器回光抽搐

### 3.2 实现要点

- **overlay**：固定定位全屏 `div#shutdown-flash`，`z-index` 高于一切（横幅之上），动画期间拦截交互（pointer-events 全开）
- **flash**：`background: #fff`（或中灰），opacity `0 → 0.95 → 0` 重复 3 次
- **灰度切换时机**：在 black 阶段（第 2 段）内给 `<html>` 添加 `grayscale(100%)`——此时页面被 overlay 完全遮住，用户看不到切换过程，reveal 亮起的已是黑白世界
- **CSS 动画**：overlay 动画用 CSS `@keyframes`（opacity 控制），JS 只负责计时触发，不做逐帧

## 4. 持续环境氛围（动画结束后）

### 4.1 灰烬飘落

- **密度**：中等——同时 20-30 片灰烬颗粒
- **视觉**：低透明度（约 0.3-0.5），灰白色颗粒，从顶部随机水平位置生成，缓缓飘落至底部后移除/循环
- **形态**：CSS 动画循环（下落 + 轻微水平摆动），大小/速度/透明度随机，避免机械感
- **遮挡**：纯视觉装饰，`aria-hidden="true"`，不拦截鼠标事件（pointer-events: none）

### 4.2 性能策略

- **常驻飘落**：动画持续存在，但用 CSS 动画（GPU 合成，低性能开销）
- **reduced-motion**：`prefers-reduced-motion` 时灰烬完全停用（见 §6.2 降级表），不播飘落动画
- **后台暂停**：监听 `visibilitychange`，页面隐藏/切后台时暂停灰烬（`animation-play-state` 或移除/暂停），回前台恢复
- **与断电动画的关系**：灰烬在 reveal 完成后才开始，不与动画冲突

## 5. 灰度控制（shutdown.css 改造）

| 场景 | 行为 |
|------|------|
| JS 正常加载 | 动画期间页面保持彩色（无 filter）→ reveal 时给 `<html>` 加 `grayscale(100%)`，此后常驻黑白 |
| JS 加载失败 / 被禁用 | `<noscript>` 内的静态 `html { filter: grayscale(100%) }` 兜底，页面黑白常驻 |
| session 已有标记 | 跳过动画，直接施加灰度，页面黑白常驻 |

> 注意：现有 `docs/css/shutdown.css` 的静态灰度需改为 JS 动态施加，否则一进页面就是黑白，"彩色→断电→黑白"的叙事不成立。

## 6. Session 去重与降级

### 6.1 Session 去重

- 用 `sessionStorage` 存标记（如 `shutdown_flash_played = '1'`）
- 页面加载时先检查：
  - **已有标记** → 跳过动画，直接灰度常驻
  - **无标记** → 播放完整断电动画，播完写入标记
- 用 `sessionStorage` 而非 `localStorage` 的理由：同一标签页内跳转任何页面整个 session 只播一次；关标签页重开则重播——既有仪式感，又不每次跳页打扰

### 6.2 降级优先级

| 场景 | 行为 |
|------|------|
| JS 正常 | 播放完整动画 → 灰度常驻 + 灰烬 |
| session 已有标记 | 跳过动画，直接灰度常驻 + 灰烬 |
| `prefers-reduced-motion` | 跳过动画与灰烬，直接瞬间切黑白（无动画） |
| JS 加载失败 / 禁用 | `<noscript>` 静态灰度兜底，无灰烬 |
| 动画中途 JS 报错 | `finalizeFlash()` 兜底：立即施加灰度 + 移除 overlay + 写 session 标记，不阻塞内容 |

### 6.3 错误处理细节

- 动画阶段用 `try/catch` 包裹
- 任何一步失败都走同一个 `finalizeFlash()`：施加灰度、移除 overlay、写 session 标记
- 保证页面**绝不会**卡在黑屏或彩色无兜底状态

## 7. 可访问性

- **纯视觉装饰**：动画与灰烬不承载文字/信息，`aria-hidden="true"`，不影响屏幕阅读器
- **prefers-reduced-motion**：检测到则完全跳过动画与灰烬，瞬间切黑白
- **闪烁控制**：3 次回光闪烁总时长 <0.4s，整屏 overlay 而非局部高频闪烁；flash 亮度用中灰而非纯白，降低光敏刺激
- **不阻塞内容**：overlay 盖在上面，页面在背后正常加载渲染；动画 <1.1s 可接受

## 9. 范围边界（YAGNI）

- ❌ 无声音（无声断电，快节奏且避免打扰）
- ❌ 无墓碑/蜡烛/悼词等悼念元素（已选定"纯黑无文字 + 断电隐喻"）
- ❌ 无 Canvas/WebGL 重渲染（纯 CSS keyframes + 轻量 JS）
- ❌ 不改造顶部常驻横幅（`shutdown-banner.js` 保持原样）
- ❌ 不新增用户设置项/关闭开关（session 去重已足够克制）

## 10. 技术栈约束

- vanilla JavaScript ES6+（IIFE，无框架）
- 纯 CSS `@keyframes`（overlay 动画 + 灰烬）
- 无新依赖
- 沿用现有 `shutdown-banner.js` 的注入模式与代码风格
